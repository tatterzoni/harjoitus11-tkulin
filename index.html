Azure-tietovisa

1. Milloin Microsoft Azure julkaistiin?

Vastaus: Vuonna 2010 (nimellä Windows Azure)

2. Mikä on Azuren tunnetuin pilvipalvelutyyppi laskennassa?

Vastaus: Virtuaalikoneet (Virtual Machines) ja App Service

3. Mitä Microsoft Azure -palvelulla voidaan tehdä?

Vastaus: Ajaa sovelluksia, tallentaa dataa, luoda tietokantoja ja rakentaa pilvi-infrastruktuuria ilman omaa palvelinsalia

4. Mitä palveluita kuuluu Azuren App Service -perheeseen?

Vastaus: Web Apps, API Apps, Static Web Apps ja Azure Functions

5. Mikä on Azuren rooli Microsoftin liiketoiminnassa nykyään?

Vastaus: Yksi Microsoftin merkittävimmistä ja nopeimmin kasvavista liiketoiminta-alueista pilvipalveluiden osalta
